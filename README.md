# react-native-ogulcan-acikel-reactnative-exc

A component developed to provide interactive graphical representation of financial data. It allows users to visualize their financial data and perform detailed analysis.

## Installation

```sh
npm install react-native-ogulcan-acikel-reactnative-exc
```

## Usage


```js
import { multiply } from 'react-native-ogulcan-acikel-reactnative-exc';

// ...

const result = await multiply(3, 7);
```
